## Остальные доработки

- JSX/CSS отформатированы, удалены устаревшие правила подписи портрета и прежнего расположения логотипов. Порядок адаптивного каскада сохранён, чтобы не менять выбранную композицию.
- Добавлены canonical, Open Graph/X, собственное превью ссылки 1200×630. Превью не загружается интерфейсом страницы.
- Содержимое пререндерится из того же React-компонента и гидратируется; без JavaScript доступны текст, навигация, native details, PDF, контакты и оригиналы изображений.
- При медленной загрузке JavaScript мобильная шапка сохраняет рабочую компоновку; отдельная регрессия задерживает модуль, проверяет читаемый первый экран и отсутствие сдвига роли после гидратации.
- Неизвестный размер нового изображения больше не приводит к падению компонента.
- Свет инициализируется при разрешённом размере/устройстве, восстанавливает потерянный WebGL-контекст, освобождает ресурсы. Отрисовка по запросу, ограничение 900×720, остановка вне экрана и скрытой вкладки сохранены. На мобильном и при reduced motion эффект отключён.
- «Слобода»: `+64 000` обозначает прирост. Radar: уточнена база сравнения прибыли. Добавлены подтверждённые +35% вовлечённости с Банком России, +30% охватов и 78% доходимости; результаты разных проектов явно разделены, дополнительные результаты свёрнуты.
- Мобильное меню закрывается по Escape, клику вне шапки, навигации и переходу на desktop.
- Совместимый Sites Worker сохраняет 404 для `/api` и `/api/*` даже при Accept: text/html; прежняя упаковка Sites сохранена.

## Приёмка и воспроизводимость

```sh
npm ci
DEPLOY_BASE=/dunaeva.a_site/ npm run build
npx playwright install --with-deps chromium firefox webkit
DEPLOY_BASE=/dunaeva.a_site/ npm test
npm run format:check
npm audit --audit-level=moderate
```

Локально проверены сборка, девять проверок motion/worker/export, форматирование и полный audit.
Браузерная матрица выполняется как обязательный этап перед публикацией Pages; результаты и снимки доступны в артефакте `browser-test-report` соответствующего запуска Actions. Проверяется production export с тем же подкаталогом, что у опубликованного сайта. CI использует официальный образ `mcr.microsoft.com/playwright:v1.63.0-noble` с готовыми браузерами и системными библиотеками, совпадающий с версией тестового пакета. Общая длительность задания ограничена 20 минутами.

Эмуляция iPhone/WebKit не заменяет проверку физического iPhone. Проверка восстановления WebGL в Chromium использует программный SwiftShader; она не доказывает FPS на реальных GPU. Реальные полевые Core Web Vitals не измерялись. Эти ограничения не следует выдавать за закрытые аппаратные проверки.
