# Исходные подписи

Утверждённые прозрачные PNG сохранены без изменений. В `public/assets` находятся уменьшенные версии для сайта и значков браузера.

Для воспроизведения оптимизации: `python scripts/optimize-signatures.py` (нужен Pillow). Исходники не входят в публичную сборку и не загружаются посетителями.
