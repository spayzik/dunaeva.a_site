# Александра Дунаева — портфолио

Редакционный сайт-портфолио SMM Lead: семь кейсов, опыт, результаты и контакты. Визуальный язык основан на выбранном концепте с крупной кириллической типографикой, монохромным портретом и бордовым акцентом. Изображения кейсов и цифры взяты из предоставленных портфолио и резюме.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`. Исходные PDF доступны из сайта в разделе опыта и в подвале.

## Структура

- `src/App.jsx` — секции, данные кейсов, навигация, раскрытие стратегии и световой WebGL-эффект.
- `src/styles.css` — адаптивная дизайн-система и анимации.
- `public/assets` — портрет и оригинальные изображения проектов из портфолио; рукописная подпись создана по выбранному концепту.
- `public/docs` — исходные PDF резюме и портфолио.

Анимации отключаются при `prefers-reduced-motion`. При отсутствии WebGL сайт работает без светового слоя.
