# Александра Дунаева — портфолио

Редакционный сайт-портфолио SMM Lead: семь кейсов, опыт, результаты и контакты. Визуальный язык основан на выбранном концепте с крупной кириллической типографикой, монохромным портретом и бордовым акцентом. Изображения кейсов и цифры взяты из предоставленных портфолио и резюме.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`. Исходные PDF доступны из сайта в разделе опыта и в подвале.

## Структура

- `src/App.jsx` — секции, данные кейсов, навигация, раскрытие стратегии и световой WebGL-эффект.
- `src/styles.css` — адаптивная дизайн-система и анимации.
- `public/assets` — портрет и оригинальные изображения проектов из портфолио; рукописная подпись создана по выбранному концепту.
- `public/docs` — исходные PDF резюме и портфолио.

Анимации отключаются при `prefers-reduced-motion`. При отсутствии WebGL сайт работает без светового слоя.

## Полный исходный код

Репозиторий содержит все компоненты, стили, эффекты, зависимости с lock-файлом, оригинальные материалы и настройки сборки. `node_modules` и `dist` создаются локально и исключены из Git.

Фирменные SVG находятся в `public/assets/logos`, происхождение указано в `public/assets/logos/SOURCES.md`. Они используются в заголовках кейсов и в опыте с сохранением пропорций и цветов.

## Движение и производительность

- Имя, портрет и вводный текст появляются последовательно; изображения кейсов раскрываются один раз при входе в экран. Наведение двигает стрелки и слегка приближает фотографии.
- Световой WebGL-слой ограничен портретом. `src/demand-renderer.js` объединяет события в один кадр: нет постоянного цикла рендеринга. Вне экрана и в скрытой вкладке кадры отменяются. Размер canvas ограничен 900×720 px, без повышения разрешения на Retina.
- На сенсорных устройствах, узких экранах и при `prefers-reduced-motion` shader не запускается. При недоступном WebGL сохраняется обычный портрет. Мобильные появления короче, настройки уменьшения движения отключают все анимации.
- Новых библиотек анимации нет. Из шрифтов исключены неиспользуемые языковые наборы; изображения кейсов загружаются лениво.
- `npm run test:motion` проверяет объединение событий, отсутствие кадров в покое, отмену вне экрана и очистку после удаления компонента. `npm run test:sites` запускается после сборки.

Период роста Telegram Wildberries — I полугодие 2026: подтверждён разделом «Ключевые результаты» исходного резюме. Формулировки личного вклада взяты из исходного портфолио.

## Бумажная фактура

Тёплая ivory-поверхность использует статичный повторяемый tile `public/assets/paper-ivory.png` (512×512 px, 91,599 байт). Палитра основана на `#f7f5ef`, с небольшим отклонением яркости для зерна и мягких волокон. Текстура лежит в фоне body: текст, фотографии, логотипы и бордовые блоки не проходят через фильтр. Нет дополнительных canvas, requestAnimationFrame, listeners или зависимостей.

Воспроизводимый генератор: `python scripts/create-paper-texture.py` (стандартная библиотека Python, фиксированный seed).

## GitHub Pages

Автоматическая публикация из `main` описана в `.github/workflows/pages.yml`. Pages использует сборку `dist/client` с `DEPLOY_BASE=/dunaeva.a_site/`; локальный режим сохраняет `/`. Изображения, логотипы, фактура, шрифты и PDF учитывают путь проекта. В Settings → Pages источник должен быть GitHub Actions.

Фирменные знаки заменяют дублирующие чёрные названия в заголовках кейсов и доступных работодателей; компании без подтверждённого логотипа сохраняют текстовое название.
